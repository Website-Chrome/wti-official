W.T.I. — Website Technologies Inventor

FILES
- index.html: complete responsive company website
- wti-logo.png: supplied W.T.I. mark, cropped for use on the website
- favicon.png: square favicon made from the supplied W.T.I. mark

GITHUB PAGES SETUP
1. Create a GitHub repository named: wti-company
2. Upload all three files to the repository root (not inside another folder).
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish the site.

BEFORE PUBLISHING
- In index.html, replace YOUR-EMAIL@example.com with the real company contact email.
- Replace the two clearly labelled concept-preview cards with real project work when available.
- The site URL will be https://YOUR-USERNAME.github.io/wti-company/ .

The favicon is linked using a relative path, so it works on a GitHub Pages project site.
